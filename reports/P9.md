# Prompt 9 Hoàn thiện yêu cầu sản phẩm

Tiếp tục trên checkpoint P8, không chạy lại A–G. Đối chiếu 121 ID thực tế trong requirements.json/XLSX và tài liệu gốc đã được đưa vào workspace.

| Phạm vi | Thay đổi | Bằng chứng và giới hạn |
|---|---|---|
| Theme | Sáng/Tối/Theo thiết bị; một Provider; lưu lựa chọn; bootstrap trong head trước nội dung; theo system change/storage event | VM test lưu/reload/system/lỗi storage; build/HTTP. Chưa kiểm first paint/hydration thật hoặc CSP trên browser |
| Màu | Token nền/chữ/muted/viền; card/form/dialog/status; nút primary giữ vàng/chữ tối; wordmark theo theme; tương phản cao ưu tiên | Đo 6 cặp màu token >=4,5. Không suy rộng thành chứng nhận WCAG AA/toàn website; chưa visual từng viewport |
| Trợ năng | Không ghi đè preference ở lần mount đầu; giữ chữ lớn/TTS/GPS; selector theme có label, panel Escape; logo PNG/font không đổi | Test bảo toàn và code review; keyboard/screen reader còn thủ công |
| Điều hướng | 5 nhóm Khám phá/Dịch vụ/Cẩm nang/Hỗ trợ/Đối tác; giữ tìm kiếm, chuyến đi, đặt chỗ, profile, SOS; native details + Escape | Test code và 203 HTTP có links/anchors; chưa thao tác dropdown trên browser |
| Tính xác thực | Camera chỉ mô tả mẫu, nhãn minh họa rõ cả TTS; tất cả luồng ticket/booking ghi demo; lỗi tải review khác empty | Source review và HTTP; không tích hợp AI/OCR/provider |
| Booking input | Ngày thực theo lịch, giờ 24h, loại số khách và max 20 đồng bộ form/API | Test ngày không có thật, giờ sai, boolean guests; API ngày còn optional để giữ tương thích, chưa chặn ngày quá khứ |
| SOS | Link tel chỉ khi có một số đủ rõ trong liên hệ do người dùng lưu, người dùng tự bấm; chuỗi mơ hồ không tự chọn | Parser test valid/missing/multiple; chưa thử dialer, GPS hay cuộc gọi trên thiết bị |
| Theo dõi yêu cầu | Giữ 121 ID và nội dung yêu cầu; cập nhật 6 loại trạng thái đúng code/test; không coi có file là hoàn thành | 32 có bằng chứng trong phạm vi, 38 một phần, 19 demo, 12 chưa triển khai, 6 cần cấu hình, 14 cần kiểm thủ công |

Các file: lib/theme.js; ThemeProvider/ThemeControl; layout/globals/tailwind; Header/Logo/AccessibilityToolbar/A11yProvider; assistant/item/notifications/sos/booking; lib/sos/validate; API bookings; tests liên quan; tracker/report. Không đổi package hoặc API route, không xóa tính năng và không tải dữ liệu đến dịch vụ ngoài.

Kết quả cuối: 42/42 test đạt; 203/203 HTTP đạt; lint 0 lỗi/11 cảnh báo; build thành công, còn 1 cảnh báo filesystem tracing. Build trước đó bắt biến phone đặt sai scope ở SOS, đã sửa và chạy lại toàn bộ; không dùng lần lỗi làm bằng chứng đạt. Playwright thiếu executable Chromium nên không có browser test.

Chưa làm vì thiếu điều kiện: DB production/migration/backup, ingress ký nguồn thực tế, tự đăng ký/recovery/MFA, provider/Guide hoạt động thật, AI/OCR/SOS tiếp nhận, quảng cáo có dữ liệu thật, khảo sát tiếp cận và những trường chưa được đơn vị cung cấp xác nhận. Không tạo nội dung hoặc dịch vụ giả để đóng gap.
